# minecraft-laucnher-modpack
Модпак и файлы конфигурации для SMP MonkeCraft
Список модов(актульная версия v1.0.2):

🌍 Мир, генерация и исследование

• Alex's Mobs | Добавляет разнообразных животных и существ, расширяя фауну игрового мира.

• Dungeons and Taverns | Добавляет новые структуры, таверны и места для исследования.

• Epic Dungeons | Создаёт масштабные подземелья с комнатами, испытаниями и наградами.

• Epic Jungle Temples | Добавляет новые вариации храмов в джунглях.

• Epic Witch Huts | Расширяет ведьминские хижины и их окружение.

• Epic Structures: Villages | Расширяет генерацию деревень, добавляя новые архитектурные вариации.

• Epic Structures: Igloo | Добавляет новые вариации иглу.

• Moogs Voyager Structures | Добавляет разнообразные структуры, которые можно обнаружить во время путешествий.

• Tectonic | Перерабатывает генерацию рельефа, создавая более выразительные горы, долины, скалы и другие природные формы.

• World of Silence | Дополняет атмосферу игрового мира.

• Glowing Torchflower | Добавляет светящиеся визуальные эффекты факелцветкам.

• LambDynamicLights | Добавляет динамическое освещение от предметов и сущностей.

• Eclipse UI | Изменяет визуальное оформление игрового интерфейса.

⚡ Оптимизация

• FerriteCore | Снижает потребление оперативной памяти за счёт оптимизации хранения игровых данных.

• ImmediatelyFast | Оптимизирует рендеринг интерфейса и других игровых элементов.

• Lithium | Оптимизирует игровые вычисления и механики, снижая нагрузку на процессор.

• ModernFix | Комплексно оптимизирует игру, загрузку и использование ресурсов.

• MoreCulling | Не рендерит объекты, которые игрок не видит.

• Entity Culling | Оптимизирует рендеринг сущностей, находящихся вне поля зрения.

• Sodium | Значительно оптимизирует графический рендеринг и повышает FPS.

• Sodium Extra | Добавляет расширенные настройки графики и оптимизации Sodium.

• Sodium Shadowy Path Blocks | Дополняет графические возможности совместимой среды Sodium.

📚 Библиотеки и технические зависимости

Большинство этих модов не добавляют самостоятельный контент. Они необходимы для работы других модификаций.

• TCD Commons | Общая библиотека для совместимых модификаций.

• Searchables | Библиотека поисковых функций для интерфейсов модов.

• Moog's Structure Library | Библиотека для модов генерации структур Moog.

• Fabric Language Kotlin | Обеспечивает поддержку модов, написанных на Kotlin.

• Modonomicon | Инструменты для создания внутриигровых книг и руководств.

• GeckoLib | Библиотека сложных анимаций моделей, сущностей и объектов.

• Fabric API | Основной API, необходимый для работы большого количества модов Fabric.

• OverlayLib | Библиотека для создания экранных оверлеев.

• Forge Config API Port | Перенос API конфигураций, необходимого некоторым модам на Fabric.

• Yet Another Config Library (YACL) | Библиотека для интерфейсов настроек модов.

• Puzzles Lib | Библиотека технических компонентов для совместимых модификаций.

• Lithostitched | Инструменты и библиотека для генерации мира и совместимых модов.

• LibJF | Общая библиотека технических компонентов для совместимых модификаций.

• Cloth Config | Библиотека интерфейсов конфигурации.

• Collective | Общая библиотека, используемая рядом модификаций.

• Placeholder API | API для работы с текстовыми плейсхолдерами и интеграциями.

• Architectury API | Универсальный API для модификаций и совместимости между платформами.

• CraftCoreLib | Библиотека технических компонентов для совместимых модов.

• MaLiLib | Библиотека, необходимая для работы Litematica и других совместимых модов.

• CodxLib | Техническая библиотека для совместимых модификаций.

• JamLib | Общая библиотека для работы совместимых модификаций.

• CreativeCore | Библиотека базовых функций для различных модов.
